Can’t connect? (CORS / https / wrong port)
Browsers only let this page talk to Ollama if Ollama allows the page’s origin. A page opened from a file has the origin null, which Ollama blocks by default. Fix once: allow all origins and fully restart Ollama (quit it from the tray icon, then start it again). 
# Windows (PowerShell)         setx OLLAMA_ORIGINS "*"
# macOS                        launchctl setenv OLLAMA_ORIGINS "*"
# Linux (systemd)              sudo systemctl edit ollama   →  add  Environment="OLLAMA_ORIGINS=*"  →  sudo systemctl restart ollama
No setting needed alternative: serve this file from localhost — in the folder run python -m http.server 8000 and open http://localhost:8000/ (Ollama allows localhost origins by default). This page also can’t call a local http:// Ollama if it is opened over https://; open the saved file instead. Install models with e.g. ollama pull qwen2.5:7b.
